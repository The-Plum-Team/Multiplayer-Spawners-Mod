# Update - 2.0.2
## New

* **Explosions no longer destroy spawners**
> TNT a player lit (or a fireball they sent back) now disables a spawner for that player, like a hit, instead of blowing it up for everyone. Any other explosion, like a creeper's, leaves it as it is. Player-placed spawners treated as vanilla still blow up.

## Compatibility

* **Spawner Control's spawn limit**
> With [Spawner Control](https://modrinth.com/mod/spawner-control)'s `spawnLimit`, a spawner that reaches its limit no longer disappears for the whole server: it runs out only for the players near it who used it up, and stays for everyone else with a fresh count. (Minecraft 1.20.1 to 1.21.5, the versions Spawner Control supports)
